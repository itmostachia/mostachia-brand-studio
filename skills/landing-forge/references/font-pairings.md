# Font Pairings — Combinaciones tipograficas probadas

20 pairings organizados por arquetipo. Cada uno incluye fuente display + body,
weights recomendados, y donde conseguirla (Google Fonts o variable font).

---

## Como usar

1. En Fase 0, el brand-extractor identifica si la marca tiene fuentes propias
2. Si NO tiene fuentes → seleccionar un pairing de este documento segun arquetipo
3. Si SI tiene fuentes → usarlas, pero consultar este doc para weights y settings
4. NUNCA defaultear a Inter sin motivo. Si Inter es la mejor opcion, documentar POR QUE

## Reglas universales de tipografia

### next/font setup
```tsx
// Siempre usar next/font para optimizacion automatica
import { Lora, Inter } from 'next/font/google';

const displayFont = Lora({
  subsets: ['latin'],
  weight: ['500', '600'],
  variable: '--font-display',
  display: 'swap',
});

const bodyFont = Inter({
  subsets: ['latin'],
  weight: ['400', '500'],
  variable: '--font-body',
  display: 'swap',
});
```

### Tailwind v4 config
```css
@theme inline {
  --font-display: var(--font-display);
  --font-body: var(--font-body);
}
```

### OpenType features (aplicar siempre)
```css
.headline {
  font-feature-settings: "kern" 1, "liga" 1, "ss01" 1;
}
.data-numbers {
  font-variant-numeric: tabular-nums;
}
```

### Scale de letter-spacing
```css
/* Adaptar segun arquetipo — estos son valores de referencia */
.display-hero  { letter-spacing: clamp(-0.5px, -2vw, -2.4px); }
.display-title { letter-spacing: -1.0px; }
.display-sub   { letter-spacing: -0.5px; }
.body          { letter-spacing: normal; }
.label         { letter-spacing: 0.5px; text-transform: uppercase; font-size: 12px; }
```
